Solar resource inputs

Monthly solar generation forecast

Enter monthly plane-of-array irradiation (GTI / POA) in kWh/m²/day from a validated resource source. The forecast uses month-specific irradiation, calendar days and the combined performance factor from the loss budget. Enter zero for months without data; incomplete data is flagged.

This is a monthly energy estimate, not an hourly simulation. It assumes entered daily monthly POA irradiation represents each month's average and applies a single combined loss factor. Validate tilt, orientation, horizon shading, clipping and seasonal operating conditions separately.

PV performance-loss budget

Enter estimated loss percentages from the project design basis or validated simulation. Losses are applied sequentially to the unadjusted reference yield; do not enter losses already included in the supplied annual yield.

Screening estimate only. Loss factors are user assumptions, not measured values. Temperature, irradiance, spectral, bifacial, clipping, degradation and system interactions may require time-series simulation. Check the definition and scope of the source yield before using this result.

Resource figures must come from a cited source or validated simulation. Degradation is a user-entered planning assumption; the projection is not a guarantee and excludes changes in availability, tariff, curtailment, soiling and future equipment replacement unless reflected in the yield input.

Structural engineering · IS 875 (Part 3) wind assessment

Preliminary wind-pressure worksheet. Select the applicable basic wind speed from the IS 875 wind map and enter the factors and pressure coefficients from the applicable code tables / project design basis.

Enter the correct Vb for the site and derive k1–k4, Kd, Ka, Kc and Cpe/Cpi from the applicable IS 875 provisions and project conditions. Default factors are placeholders, not approved code selections.

Mounting structure · rail / purlin member screen

Transfer the calculated roof wind pressure and mounting dead load to a simply supported rail or purlin. Enter the actual member span, tributary width and section properties from the selected manufacturer / steel section. This is a beam-screening worksheet, not a complete mounting-system approval.

Calculate the IS 875 wind assessment first. Wind pressure is transferred using this member's tributary width. Defaults are example inputs only; replace them with verified project values.

Structural member resistance screen · gross-section reference

Compare the user-defined ULS load-combination envelope against a transparent gross-section elastic yield reference and a supplied shear area. This is not a complete IS 800 member design: section classification, lateral-torsional buckling, local buckling, web buckling, interaction and connection effects are not evaluated.

Calculate load combinations first. Enter actual steel grade and manufacturer section properties. A zero shear area means no shear resistance can be assessed.

Lateral-torsional buckling · elastic critical moment reference

For a doubly symmetric I-section only, estimate the elastic critical moment using entered manufacturer section properties and an engineer-verified moment-gradient factor C1. This is an elastic stability reference, not an IS 800 design resistance or a pass/fail check. The model assumes a prismatic, elastic member with ideal fork-type end restraint, no destabilising load-height effect and the stated unbraced length.

Use properties from the exact section and confirm units, symmetry, restraint, load application height and C1 with the structural engineer. Do not use Mcr as design moment capacity.

Steel section element classification · engineer-verified limits

Record the measured flange outstand and web slenderness ratios for the actual section. Enter the Class 1, 2 and 3 limiting ratios from the applicable IS 800 Table 2 row for the actual element stress condition. The app deliberately does not guess code limits: flange stress state, web stress gradient and section form affect the correct row. A result is only a screening classification from the limits you supply.

No classification has been calculated. Verify the selected IS 800 Table 2 stress-condition row and all limits with the project structural engineer.

Structural load combinations · user-defined factors

Combine characteristic member line actions for a simply supported uniformly loaded member. Enter Gk and Qk downward, and Wk as a positive uplift magnitude. Factors are editable project inputs: select and verify them against the governing code, project importance, limit state and load case. The worksheet does not select code combinations automatically.

Illustrative factor defaults only. Confirm the governing IS 875 / IS 800 / IS 456 provisions, load categories, simultaneous action rules and project-specific design basis. This worksheet does not establish compliance or replace a complete structural analysis.

Mounting connections · clamps & anchor group demand screen

Estimate module clamp uplift, rail-support reaction transfer and anchor-group tension / shear demand using the previous member screen. Enter manufacturer or engineered design resistances; do not use generic catalogue values.

Calculate wind and mounting member actions first. Enter verified design resistances from the selected clamp / anchor system and supporting substrate design. Zero resistance means capacity has not been supplied and no pass can be reported.

RCC footing design · flexure and shear screening

Preliminary isolated square/rectangular footing design under a column/pedestal. Enter pedestal dimensions, footing thickness, concrete and steel grades, clear cover, bar diameter and factored column actions. Uses a one-way cantilever strip and critical punching perimeter at d/2.

Calculate foundation geometry first. This module screens flexure, one-way shear and punching shear with simplified assumptions. It does not issue reinforcement drawings or construction approval.

RCC footing reinforcement detailing · indicative schedule & drawing

Generate a bottom reinforcement bar schedule and dimensioned plan/section from the saved RCC footing screen. Bar lengths are straight cut lengths inside clear cover; verify actual bends, hooks, laps and anchorage on approved structural drawings.

Calculate the RCC footing screen, then generate reinforcement detailing.

Indicative detailing only. Entered Ld is a review target, not an automatically verified IS 456 development length. This drawing does not design hooks, bends, laps, column dowels, top steel, punching reinforcement or construction joints.

Foundation & base stability · preliminary screen

Transfer the mounting support reactions to a simplified isolated-footing check. Enter footing dimensions, verified footing and supported dead load, soil allowable bearing pressure, horizontal action and its lever arm. This is a rigid-footing screening model only.

Calculate wind and mounting member actions first. Soil parameters and load combinations must come from the geotechnical report and applicable design code.
